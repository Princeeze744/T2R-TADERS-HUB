# T2R Lab Results

Trade2Retire Academy research site: nine zone strategies tested on 150 markets.

- `app/` Next.js pages (App Router). `app/api/` is where the Telegram bot and database link will live.
- `public/lab.js` the dashboard logic.
- `public/data/lab.json` the results data. Replace this file to publish a new scan.

Local: `npm install`, then `npm run dev` and open http://localhost:3000
Deploy: push to GitHub; Vercel builds it automatically.
